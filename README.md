# Casa do Barbudo

Site institucional da Casa do Barbudo Barbearia, Gravatá/PE.

## Desenvolvimento

Requer Node.js compatível com Vite 8.

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
node scripts/verificar-conteudo.mjs
```

A pasta `dist/` contém o site pronto para hospedagem estática. O upload do repositório não ativa hospedagem automaticamente.

Fotos originais e arquivos internos de trabalho não estão incluídos.
